# Beta Function B(x, y) Calculator

SOEN 6011 - Software Engineering Processes (Summer 2026)
Individual project implementing the Beta function B(x, y).

## What it does

Computes B(x, y) using numerical integration (Simpson's Rule),
built from scratch in Python (no external math libraries).

## Files

- `beta_function_scratch.py` — core math logic (from-scratch exp, ln, power, and the Beta function itself)
- `beta_function_gui.py` — Tkinter GUI for entering x and y and viewing the result

## How to run

```
python3 beta_function_gui.py
```

Enter positive real values for x and y, then click **Calculate**.
